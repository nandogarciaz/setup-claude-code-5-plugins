# 5 plugins pra potencializar o seu Claude Code

Guia gratuito com o passo a passo para instalar e usar 5 ferramentas no Claude Code:

1. **Claude Code Setup**: plugin oficial da Anthropic que analisa o seu projeto e recomenda automações.
2. **Claude-Mem**: memória entre sessões.
3. **Headroom**: compressão de contexto para gastar menos tokens.
4. **Task Observer**: skill que observa seu jeito de trabalhar e sugere melhorias nas suas skills.
5. **OmniRoute**: gateway que conecta vários provedores de IA e troca de provedor quando um bate o limite.

👉 **Acesse o guia:** https://nandogarciaz.github.io/setup-claude-code-5-plugins/
