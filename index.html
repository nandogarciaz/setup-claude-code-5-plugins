5 plugins pra potencializar o seu Claude Code

O passo a passo pra instalar e começar a usar cada ferramenta do vídeo. Copie os comandos e cole no terminal ou no Claude Code.

Claude Code Setup Claude-Mem Headroom Task Observer OmniRoute
ANTES DE COMEÇAR

O que você precisa

Todos os plugins funcionam em cima do Claude Code. Confira se você já tem o básico instalado:

Claude Code atualizadoCom suporte a plugins. Rode claude update se estiver numa versão antiga.
Node.js 20 ou superiorUsado pelo Claude-Mem, Task Observer e OmniRoute.
Python 3.10 ou superiorSó para o Headroom.
Onde digitar cada comando Os comandos que começam com / são digitados dentro do Claude Code. Os outros vão no terminal do seu computador.
PLUGIN 01 / 05

Claude Code Setup

Plugin oficial da Anthropic que analisa o seu projeto e recomenda o que vale configurar: servidores MCP, skills, hooks, subagentes e comandos. Ele só lê e sugere, não altera nenhum arquivo.

Marketplace oficial ↗ Gratuito

Como instalar

  1. Abra o terminal na pasta do seu projeto e inicie o Claude Code.
    terminal
    claude
  2. Dentro do Claude Code, rode o comando de instalação. Ele abre os detalhes do plugin.
    claude code
    /plugin install claude-code-setup@claude-plugins-official
  3. Escolha o escopo: só para você em todos os projetos, para todo mundo do repositório, ou só para você neste projeto. Se aparecer o aviso pedindo recarregar, rode /reload-plugins.

Como usar

  1. Peça a análise em linguagem natural:
    claude code
    Recomende automações para este projeto
  2. Ele mostra as melhores sugestões por categoria. Para ver mais opções de uma categoria, peça só ela, por exemplo: "quais hooks você recomenda?".
  3. Escolha o que faz sentido e peça para o Claude configurar. Nada é instalado sem você pedir.
PLUGIN 02 / 05

Claude-Mem

Memória entre sessões. Registra automaticamente o que acontece em cada sessão, resume e guarda tudo localmente. Na sessão seguinte, traz de volta o contexto que importa.

github.com/thedotmack/claude-mem ↗ Código aberto

Como instalar

  1. Dentro do Claude Code, adicione o marketplace do projeto:
    claude code
    /plugin marketplace add thedotmack/claude-mem
  2. Instale o plugin:
    claude code
    /plugin install claude-mem
  3. Feche e abra o Claude Code de novo. A partir daí, o contexto das sessões anteriores aparece sozinho nas novas.
Prefere instalar pelo terminal?
terminal
npx claude-mem install

Não use npm install -g claude-mem: esse comando instala só a biblioteca e não ativa a memória no Claude Code.

Dicas de uso

  • Tudo fica salvo no seu computador, na pasta ~/.claude-mem/.
  • Quer que algo não seja guardado? Coloque o trecho entre as tags <private> e </private>.
  • No Windows, se a memória não funcionar, rode npx claude-mem doctor para diagnosticar.
PLUGIN 03 / 05

Headroom

Um funil de contexto. Fica entre o Claude Code e o modelo e enxuga logs, JSON e saídas de ferramentas antes do envio, mantendo o que importa, como os erros. Resultado: menos tokens e mais espaço na janela de contexto.

github.com/headroomlabs-ai/headroom ↗ Código aberto

Como instalar

  1. No terminal, instale a ferramenta. Se você usa o uv, este é o jeito mais limpo:
    terminal
    uv tool install --python 3.13 "headroom-ai[all]"
    Sem o uv, use o pip:
    terminal
    pip install "headroom-ai[all]"

Como usar

  1. Em vez de abrir o Claude Code com claude, abra pelo Headroom:
    terminal
    headroom wrap claude
  2. Use o Claude Code normalmente. O Headroom comprime o contexto no caminho, e o original fica guardado localmente caso o modelo precise dele.
Quanto economiza? Depende do tipo de conteúdo: logs e JSON repetitivos rendem bem mais que código. Teste no seu dia a dia antes de contar com um número.
PLUGIN 04 / 05

Task Observer

Uma skill que observa como você trabalha. Quando percebe que você corrige a mesma coisa várias vezes, anota e sugere uma melhoria na skill certa. Nada é instalado sozinho: você revisa e aprova.

github.com/rebelytics/one-skill-to-rule-them-all ↗ Guia do autor ↗

Como instalar

  1. No terminal, dentro da pasta do projeto, instale a skill:
    terminal
    npx skills add rebelytics/one-skill-to-rule-them-all --skill task-observer
    Para valer em todos os projetos, adicione -g no fim do comando.
  2. Ative a skill no início de cada sessão. Abra o arquivo references/environments.md que veio com a skill, copie o bloco de ativação para Claude Code e cole no CLAUDE.md do seu projeto, preenchendo os caminhos indicados.
  3. Abra uma sessão nova no Claude Code e trabalhe normalmente.
Como saber se está funcionando Depois de algumas sessões, deve aparecer a pasta skill-observations/observation-log/. As sugestões de melhoria ficam em skill-updates/, esperando a sua revisão.
PLUGIN 05 / 05

OmniRoute

Um gateway de IA que roda na sua máquina. Você conecta vários provedores pelas suas chaves de API, vários com plano gratuito, e aponta o Claude Code pra ele. Quando um provedor bate o limite, ele troca sozinho pro próximo da fila.

github.com/diegosouzapw/OmniRoute ↗ Código aberto

Como instalar

  1. No terminal, instale e inicie o OmniRoute:
    terminal
    npm install -g omniroute
omniroute
  2. Abra o painel no navegador:
    navegador
    http://localhost:20128
  3. No painel, conecte os provedores que você vai usar com a sua conta ou chave de API de cada um. A ordem da fila define quem é chamado primeiro.
Prefere usar Docker?
terminal
docker run -d --name omniroute --restart unless-stopped \
  -p 127.0.0.1:20128:20128 -v omniroute-data:/app/data \
  diegosouzapw/omniroute:latest

Como ligar no Claude Code

  1. Rode o configurador e escolha o modelo na lista:
    terminal
    omniroute configure claude
  2. Ou abra o Claude Code direto pelo OmniRoute, sem mexer em configuração nenhuma, trocando o modelo pelo que você conectou:
    terminal
    omniroute run claude --model provedor/modelo
Antes de usar, leia isto Cada provedor tem as suas regras e limites no plano gratuito, e alguns não permitem uso por ferramentas de terceiros. Confira os termos de uso de cada um antes de conectar. Suas chaves ficam na sua máquina: mantenha o OmniRoute atualizado e não exponha a porta 20128 na internet.
